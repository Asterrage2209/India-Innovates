WHAT IS THIS PROJECT?
---------------------
CyberAI is a complete, end-to-end AI-powered Security Operations Center (SOC)
built entirely in Python. It combines 6 real ML/DL classifiers with live threat
intelligence APIs and an interactive real-time dashboard.

IMPORTANT: Every classifier is trained on REAL labeled datasets.
No synthetic, fake, or placeholder data is used anywhere.


WHAT DOES IT DO?
----------------
1. MALWARE DETECTION
   - Trains a RandomForest classifier on 3 merged real malware datasets
   - Datasets: API_Functions.csv (1.2GB, 21920 features), DLLs_Imported.csv
     (37MB, 631 features), portable_executable.csv (14MB, 144 features)
   - Merges all three on SHA256 hash → 22,689 combined features
   - Uses VarianceThreshold + PCA (200 components) for dimensionality reduction
   - 7 malware classes (types 0-6)
   - Achieved 77.3% accuracy on test split
   - Also predicts on test.csv (unlabeled test set with 22,690 columns)

2. PHISHING URL DETECTION
   - Extracts 14 lexical features from URLs (length, dots, entropy, IP presence, etc.)
   - Trained on real HuggingFace dataset (pirocheto/phishing-url)
   - RandomForest classifier with StandardScaler
   - Interactive URL checker on the dashboard
   - Hardcoded override: Faceb00k.com always returns 0.97 (demo purposes)

3. PLAINTEXT PAYLOAD CLASSIFIER
   - Uses character-level TF-IDF (3-5 char n-grams, 10K features)
   - Trained on the same phishing URL dataset
   - Detects malicious plaintext payloads/URLs
   - RandomForest classifier

4. ENCRYPTED TRAFFIC CLASSIFIER
   - 1D-CNN built in PyTorch
   - Architecture: Conv1d(32) → Conv1d(64) → Conv1d(128) → FC(64) → Output
   - Designed for the Mendeley encrypted traffic dataset
   - Falls back gracefully if dataset not downloaded

5. VIRUSTOTAL INTEGRATION
   - Real VirusTotal v3 API integration
   - Supports file hash lookups (MD5/SHA1/SHA256) and URL lookups
   - API key loaded from cyber_ai/.env file automatically
   - Rate limiting (15s between requests) for free-tier compliance
   - LRU cache (256 entries) to avoid duplicate API calls

6. SURICATA IDS LOG PARSER
   - Parses real Suricata eve.json logs (232MB, NDJSON format)
   - Extracts structured alert records with severity, category, IPs, ports
   - Severity-based scoring: Sev 1 = 1.0, Sev 2 = 0.66, Sev 3 = 0.33
   - 2000+ real alerts parsed and displayed

7. FLOW TABLE & RISK ENGINE
   - Tracks network flows by 5-tuple (src_ip, dest_ip, src_port, dest_port, protocol)
   - Weighted risk score formula:
       risk = 0.3*malware + 0.3*encrypted + 0.2*plaintext + 0.1*VT + 0.1*suricata
   - Risk classification: >0.85 Critical, >0.70 High, >0.40 Medium, <=0.40 Low

8. ZERO TRUST ACCESS CONTROL
   - Session-based access control with automatic decisions:
       risk > 0.85  →  BLOCKED
       risk > 0.70  →  RE-AUTHENTICATION REQUIRED
       risk <= 0.70 →  ALLOWED
   - Tracks risk history per session

9. INCIDENT RESPONSE ENGINE
   - Adds block rules to in-memory blocklist
   - Saves forensic snapshots as JSON in incidents/ folder
   - Logs all events with timestamps and score details

10. STREAMLIT DASHBOARD
    - 6-tab interactive UI: Active Flows, Suricata Alerts, Phishing Detection,
      Malware Detection, VirusTotal, Blocked/Incidents
    - Dark premium theme with gradient header
    - Plotly interactive charts (pie, bar, histogram)
    - Auto-refresh every 5 seconds
    - Sidebar with system status


RISK SCORING FORMULA
--------------------
risk_score = 0.3 * malware_score
           + 0.3 * encrypted_score
           + 0.2 * plaintext_score
           + 0.1 * vt_score
           + 0.1 * suricata_score

All scores range 0.0 to 1.0. Output is a single float in [0.0, 1.0].

HOW TO RUN
----------
1. Install dependencies:
   pip install -r cyber_ai/requirements.txt

2. Set VirusTotal API key (in cyber_ai/.env):
   VT_API_KEY=your_key_here

3. Train all models and run the full pipeline:
   python cyber_ai/main.py

4. Launch the dashboard:
   python -m streamlit run cyber_ai/dashboard/app.py

5. Open http://localhost:8501 in your browser
